# Alma Floral

Proyecto académico del curso Herramientas de Desarrollo de la
Universidad Tecnológica del Perú.

## Descripción

Alma Floral es un proyecto de sistema web orientado a centralizar
el catálogo de productos, el registro y la gestión de pedidos,
y la atención postventa de una florería.

## Objetivo

Implementar un sistema web para mejorar la gestión de ventas
de Alma Floral mediante la digitalización del catálogo,
los pedidos y el seguimiento de la atención al cliente.

## Funcionalidades previstas

- Consulta del catálogo digital.
- Registro y consulta de pedidos.
- Administración de productos y existencias.
- Actualización de estados de pedidos.
- Registro y seguimiento de solicitudes postventa.
- Acceso autenticado al panel administrativo.

## Tecnologías previstas

- C# y ASP.NET Core MVC.
- SQL Server Express.
- Visual Studio Code como editor de desarrollo.
- Git y GitHub para el control de versiones.

## Organización de ramas

- main: versiones estables y revisadas.
- develop: integración de los avances del proyecto.
- feature/nombre: desarrollo de funcionalidades específicas.
- docs/nombre: cambios de documentación.
